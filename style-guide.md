## Typography
- Headings: Georgia, 'Times New Roman', serif. 34/42px desktop, 28/36px mobile, normal weight, centered. The reference uses a high-contrast serif; Georgia is the safe system equivalent.
- Body: Arial, Helvetica, sans-serif, 16/27px.
- Closing line: Georgia 20/30px. Footer: Arial 12 to 13px.
- Button: Arial bold 14px, letter-spacing 2px, uppercase (the only uppercase element).

## Spacing and button
- Canvas 600px max, fluid below. Side padding 56px desktop, 24px mobile. Headline block starts 56px below the hero; the button has 36px above and 64px below.
- Button: #A65D74, white text, 18px/40px padding (52px tall), 2px radius, full-width on mobile. Outlook gets a VML button (260x52).
